# Architecture initiale KineTrack

## Structure

- `frontend/` : application React (Vite + Tailwind + Router)
- `backend/` : API FastAPI + accès MongoDB via Motor
- `docs/` : documentation du projet

## Modules fonctionnels prévus

- `patients`
- `agenda`
- `portail patient`
- `ia`
- `sms`

Ces modules sont seulement préparés dans l'architecture pour l'étape 1.
